🚆 Smart Train Tracking System

A web-based train tracking system designed to help commuters monitor train locations, estimated arrival times, and train status in real time.

📌 About the Project

The Smart Train Tracking System provides passengers with an easy way to view train locations, estimated arrival times, station information, and important service announcements.

✨ Features

- 🚆 Real-time train tracking
- ⏱️ Estimated Time of Arrival (ETA)
- 📍 Train station monitoring
- ⚠️ Train malfunction and delay alerts
- 🎫 Train booking simulation
- 📱 QR code generation
- 💳 Beep Card top-up simulation
- 👨‍💼 Admin dashboard
- 📊 Train status monitoring

💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Leaflet.js
- Chart.js

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. The system will automatically load.
